# Требования — ORTO Prosthesis Annotator 0.1.0 TEST

## Назначение и область применения

Локальный инструмент подготовки размеченных данных для последующей разработки модели семантической сегментации 3D-сканов протезов голени.

Поддерживаются:
- полный скан собранного протеза голени;
- скан, в котором соединитель частично закрыт гильзой и/или стопой.

Протезы бедра не входят в текущую область применения.

## Классы

| ID | Класс | Назначение |
|---:|---|---|
| 0 | Не размечено | Исходное состояние, ещё не размеченная поверхность |
| 1 | Гильза | Поверхность гильзы |
| 2 | Соединитель | Видимые поверхности адаптеров, пилона и соединительных элементов |
| 3 | Стопа | Поверхность протезной стопы |
| 4 | Неопределённо | Видимая поверхность, класс которой оператор не может уверенно определить |

Не следует синтетически достраивать невидимые или отсутствующие поверхности. Если соединитель закрыт, размечается только его видимая поверхность.

## Функциональные требования первого этапа

1. Открытие STL и отображение единой поверхности.
2. Вращение, панорамирование и масштабирование модели.
3. Выбор семантического класса.
4. Нанесение меток на поверхность кистью с регулируемым радиусом.
5. Смена класса уже размеченной области.
6. Сохранение проекта и восстановление разметки только при совпадении fingerprint исходной геометрии.
7. Экспорт координат вершин, треугольной связности и меток граней.
8. Отсутствие сетевых запросов и облачной обработки.
9. Запрет на коммит сканов и пользовательских проектов в Git.

## Критерии приёмки 0.1.0

- Приложение запускается на Windows в поддерживаемом Python-окружении.
- STL открывается без изменения исходного файла.
- Визуально различимы все пять состояний меток.
- Оператор может наносить и исправлять метки.
- Проект сохраняется и загружается только для той же геометрии.
- Экспорт содержит исходные координаты, connectivity и одну метку на грань.
- Неполная разметка явно помечается как неготовая для обучения.
- В репозитории отсутствуют реальные сканы и персональные данные.

## За пределами первого этапа

- Обучение нейросети и инференс.
- Автоматическое определение границ.
- Автоматическая ориентация протеза.
- Совмещение с косметической оболочкой.
- Поддержка протезов бедра.
