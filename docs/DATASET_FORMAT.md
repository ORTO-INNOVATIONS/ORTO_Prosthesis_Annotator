# Формат обучающих данных

## Идентичность исходной сетки

Fingerprint SHA-256 вычисляется по:
1. форме массива координат;
2. упорядоченным координатам вершин float64;
3. упорядоченному массиву треугольной connectivity.

Это предотвращает применение меток к другой геометрии или к STL с изменённым порядком треугольников.

## Файлы экспорта

- `<scan>.labels.npz` — массивы vertices, faces, face_labels.
- `<scan>.labels.json` — метаданные и статистика классов.

## Семантика

| ID | Значение |
|---:|---|
| 0 | UNLABELED |
| 1 | SOCKET |
| 2 | CONNECTOR |
| 3 | FOOT |
| 4 | UNCERTAIN |

`UNCERTAIN` — видимая поверхность, для которой оператор не уверен в классе. Это не эквивалент отсутствующей поверхности.

`UNLABELED` — поверхность, которую оператор ещё не разметил.

## Готовность к обучению

Экспорт помечается `training_ready=true` только если каждая грань имеет значение, отличное от UNLABELED. Это не означает, что разметка прошла экспертную проверку: контроль качества остаётся отдельным процессом.

Не добавляйте сканы пациентов, имена, номера заказов или иные идентификаторы в Git.
